## Оценка приоритетов проверки модулей безопасности

**Ключевые потребности бизнеса и проблемы с ИБ:**

1) Нарушен контроль данных
2) Внутренние потоки данных между IT-продуктами контролируются не системно
3) Со стороны систем обработки данных нет ограничений на доступ к данным
4) Утечка ПД клиентов через API для партнеров
5) Нарушение ролевой модели в публичном API
6) Расширение через API - один из ключевых факторов развития бизнеса
7) Нарушение RBAC модели в клиентском приложении
8) Компания хочет начать анализировать накопленные данные. Без контроля за данными это невозможно
9) Предотвратить утечки данных
10) Проверка корректности работы с разными категориями данных с точки зрения законодательства
11) Неоднотипная инфраструктура серверов

Большая часть проблем и приоритетов компании касается контроля за доступом к данным и обеспечения безопасности данных.
Кроме
этого в виду разнородной серверной инфрустуктуры необходимо уделить внимание базовой проверки безопасности серверов и
облака.

Таким образом приоритетными для компании направлениями аудита должны стать

1) Управление доступом
2) Безопасность данных
3) Защита инфраструктуры
4) Управление оборудованием и физической безопасностью
